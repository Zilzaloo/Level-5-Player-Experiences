Package Contents

11 Stylized Rock Models (FBX + Unity prefab)

4K Albedo Texture (PNG)

Materials for Unity (default: Standard/URP Lit)

🚀 How to Import

Open your Unity project (Unity 2021.3 LTS or newer is recommended).

Go to Assets > Import Package > Custom Package.

Select the downloaded .unitypackage file and import all contents.

You will find the assets inside the folder:
Assets/StylizedRocks/

🎨 Render Pipeline Compatibility

Built-in Render Pipeline – Works out of the box.

URP (Universal Render Pipeline) – Materials are already compatible.

HDRP (High Definition Render Pipeline) – Please convert materials:

In Unity, go to: Edit > Render Pipeline > Upgrade Project Materials > HDRP.

All materials will update automatically to HDRP/Lit.
